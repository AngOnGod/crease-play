# CREASE

A field lacrosse game that runs in the browser. Full-field 10 v 10 against the AI, a shooting range and a 3 v 3 sandbox.

**Play it: https://angongod.github.io/crease-play/**

- Use Chrome on a laptop or desktop. A controller works; so does the keyboard.
- Keyboard: W A S D to move, J pass, K shoot, L fake, Space to square up on defense, left Shift to sprint. Every binding is listed and can be changed under Controls.
- If it runs slowly, lower Quality or Render scale under Settings.

This is an early build of a game still being made. Beside its own invented league it has all-time teams for 12 college programs.

**An unofficial fan project.** It is not affiliated with, sponsored by or endorsed by any school, conference, the NCAA or any player. It uses no school logo, wordmark or likeness: the badges and uniforms are the game's own, and every player has the same generic body. Names, seasons, listed sizes and honours come from public records; the ratings and the notes on how each man played are the game's opinion. The game is free. If you are named in it and would rather not be, open an issue on this repository and you will be taken out.
